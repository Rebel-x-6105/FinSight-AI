ABOUT THE PROJECT

Building smarter financial understanding with FinSight AI.

FinSight AI is an intelligent personal-finance and spending analytics platform designed to help users understand their financial behavior instead of simply recording transactions.

CURRENT DEVELOPMENT STAGE

Phase 1

Flask Foundation

The current focus is building the Flask application structure, frontend interface, forms, routing, Jinja templates, and responsive design.

In Development

THE IDEA

More than an expense tracker

Traditional expense-tracking applications mainly show users where their money has already been spent. FinSight AI is being designed to go further by analyzing financial patterns and eventually using machine learning to produce meaningful insights.

The goal is to transform transaction data into information that helps users better understand savings, expenses, habits, recurring payments, unusual transactions, and possible future spending.

PROJECT DIRECTION

From financial data to useful intelligence

FinSight AI is planned as a combination of web development, database systems, analytics, and machine learning.

01

Track

Users will record income and expenses and eventually upload financial transaction data.

02

Analyze

Financial data will be processed to understand spending categories, savings, and recurring behavior.

03

Predict

Machine-learning models will eventually be used to identify anomalies and forecast future expenses.

04

Understand

The platform will combine analytics and predictions into personalized financial insights.

FUTURE INTELLIGENCE

Planned machine-learning capabilities

These capabilities belong to later development phases and are not implemented in Phase 1.

◉

Spending Personality Classification

K-Means clustering will be explored to classify financial behavior using savings and category-level spending patterns.

!

Transaction Anomaly Detection

Isolation Forest will be explored to identify transactions that differ significantly from normal spending behavior.

↗

Expense Forecasting

Linear and Ridge Regression will be explored to estimate future spending using previous monthly expense patterns.

↻

Subscription Detection

Recurring merchant names, transaction amounts, and payment intervals will be analyzed to identify possible subscriptions.
